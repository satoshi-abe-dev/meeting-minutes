# examples/

**非機密の動画**を実際に処理して得た議事録の実物を置く場所。「動いた証拠」を
リポジトリに残すためのもの。

## `output/` との違い

| | `output/` | `examples/`（ここ） |
| --- | --- | --- |
| 中身 | 実行のたびに生成される作業データ | 意図して選んだ 1 件の完成例 |
| Git | `.gitignore` で除外 | **コミットする** |
| 元動画 | 何でも（機密含む） | 公開・非機密のものだけ |

## 追加予定（フェーズ2）

非機密のサンプル動画（公開講演・勉強会の録画、またはダミー会議の自前録画）を
1 本処理し、次を置く:

```
examples/<サンプル名>/
├── minutes.md          生成された議事録
├── minutes.docx        同じ議事録の Word 版（minutes.md から自動生成。任意）
├── transcript.head.txt 文字起こしの冒頭だけ（雰囲気が分かる程度）
└── frame_sample.jpg    代表フレーム 1 枚（任意）
```

README のデモ節からここへリンクする。

> 現在処理中の実会議（顧客情報を含む）の出力は、ここには置かない。
